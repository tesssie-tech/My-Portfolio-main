# Akuruli .o. Theresa Portfolio

## Description

This is a modern portfolio showcasing frontend development, illustration, and branding work. It's designed to be responsive and visually engaging, highlighting key projects and skills.

## Features

*   **Responsive Design**: Optimized for various screen sizes and devices.
*   **Featured Projects Carousel**: Dynamically displays a selection of key projects with navigation.
*   **Project Gallery**: A comprehensive gallery showcasing all projects, with detailed modals for each.
*   **Dynamic Skills Section**: Highlights a range of technical and creative skills.
*   **Interactive Experience Timeline**: Details professional and volunteer experiences.
*   **Certifications Section**: Lists completed certifications.
*   **Functional Contact Form**: Powered by Formspree for easy communication.
*   **Custom Favicon and Title**: Personalized browser tab experience.
*   **Smooth Scrolling Navigation**: Seamless navigation to different sections of the page.

## Setup

To get a local copy up and running, follow these simple steps.

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/tesssie-tech/your-portfolio-repo-name.git
    # Replace `your-portfolio-repo-name` with the actual name of your GitHub repository.
    ```
2.  **Navigate to the project directory**:
    ```bash
    cd "2026 graphic design portfolio"
    ```
3.  **Install dependencies**:
    ```bash
    npm install
    ```
4.  **Run the development server**:
    ```bash
    npm run dev
    ```
    The application will typically open in your browser at `http://localhost:5173` (or another port if 5173 is in use).

## Deployment

This project is set up for easy deployment to platforms like Render.

1.  **Push your code to GitHub**: Ensure all your latest changes are pushed to your GitHub repository.
2.  **Create a Render account**: Sign up at render.com.
3.  **Create a new Static Site**: Connect your GitHub repository, set the build command to `npm install && npm run build`, and the publish directory to `dist`.
